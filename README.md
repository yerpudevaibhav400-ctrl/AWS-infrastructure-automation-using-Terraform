
# AWS Infrastructure Automation using Terraform

## Project Overview
This project demonstrates Infrastructure as Code (IaC) concepts using Terraform for AWS infrastructure.

## Technologies Used
- AWS
- Terraform
- Amazon EC2
- AWS VPC
- AWS IAM

## Key Features
- Automate AWS resource provisioning
- Define infrastructure using Terraform configuration
- Understand cloud infrastructure management
- Learn Infrastructure as Code (IaC)

## Learning Outcomes
- Understand Terraform basics
- Learn AWS infrastructure automation
- Understand resource management
